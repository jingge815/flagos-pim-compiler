# 功能分支合并记录（2026-11-07）

## 范围

- `flagos-pim-compiler`：将 `feature` 合并到 `main`。
- `flagOS-installers/FlagTree`：将 `feature` 合并到 `develop`。
- `genesim`：将 `feature` 合并到 `fjg-dev`。两条历史虽然没有共同提交，但 `feature` 初始树与 `abb1715` 完全一致，因此以该快照为共同基线做三方合并。

## 功能保留

### 图编译器与运行时

- 保留 `main` 的 Ceva 导出、图优化、权重分块、DMA 对齐和无 GPU 前端编译路径。
- 保留 `feature` 的 Qwen2/Qwen3/Qwen3-MoE、偏置、RMSNorm 融合、vLLM、请求并行、KV 块循环和 GeneSim 成本标注。
- 图优化作用于全部 prefill 长度桶和 decode 图，然后再做切分传播。
- 线性计算先加可选偏置，再执行可选尾部激活；带偏置时仍按原约定退回 NumPy 镜像。
- 执行计划同时保留同泳道依赖压缩、MoE 动态分派和融合算子命令。
- `main` 已删除的旧 orchestrator 不恢复；`feature` 已清理的无效导入和过期文档不恢复。

### FlagTree

合并无文本冲突，保留分页注意力方言算子、单遍在线 softmax、相位 `perBlock`/`poolBytes` 属性、契约校验和 EmitC 降低。

### GeneSim

保留 `fjg-dev` 的结构化日志、性能总结和请求上下文，同时加入 `feature` 的融合注意力 ModelIR、KV 块计费、算子类型时间归因和调度器清理。`src/main.py` 继续输出 `op_type_metrics.json`。
